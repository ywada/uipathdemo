UiPath セレクタ検証ページ

aaname が取れず、idx や tableRow / tableCol で特定することになる画面要素の検証用ページです。テスト対象には id・name・title・aria-label・placeholder・label・表示テキストを付けていません。B〜D はクラス名もすべて共通です。A だけは class に色名が入っていて、class で区別できます。

A. 色付きカード（class で区別）

表示テキストのない div カードです。aaname は空ですが、class に色名（red / blue / green / yellow / purple / orange）が入っています。UI Explorer で idx の代わりに class を選び直すと、シャッフルしても同じカードを選べる想定です。クリックで選択状態が切り替わります。

B. アイコンだけのボタン（idx で区別）

テキストのない同じ形のボタンが8個並んでいます。位置（idx）でしか区別できません。

C. テーブル内の入力欄・チェックボックス・ボタン（tableRow / tableCol で区別）

各行に同じ要素が並んでいます。行番号・列番号で位置を指定する想定です。

Noコード選択数量操作

D. ラベルのないテキストボックス（idx で区別）

ラベル・placeholder・name のない入力欄が5個並んでいます。

操作ログ

どの要素が操作されたかを表示します。「並び順シャッフル」を押すと A・B・D の並び順が変わり、idx に依存したセレクタが別の要素を指すことを確認できます。
